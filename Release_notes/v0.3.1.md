# v0.3.1

## Project hygiene and review intake

`v0.3.1` does not add or change manifest-analysis findings. It improves the
project's maintenance and review surfaces:

- pins the test workflow's GitHub Actions to reviewed commit SHAs;
- adds a security reporting policy and contribution guidance; and
- adds issue forms for incorrect or missing findings, unsupported inputs, and
  potentially misleading security claims.

## What did not change

The analysis boundary remains unchanged. `kube-blast-radius` is an offline tool
for explicitly supplied manifest changes. It does not access a Kubernetes
cluster, kubeconfig, registry, credentials, Secret values, runtime routing, or
cloud IAM.

## Release assets

- `kube-blast-radius_v0.3.1_linux_amd64.tar.gz`
- `checksums.txt` for the archive and `sbom.cdx.json`
- `sbom.cdx.json`, a minimal CycloneDX 1.5 SBOM

Verify both checksummed assets after download:

```sh
sha256sum -c checksums.txt
```
